## A. 甄别问卷（6 步）

| # | 现在 | 改成 |
|---|---|---|
| A1 | ① 读取立项有“去立项改”按钮 | 删掉这个按钮。右侧的研究背景、研究目标、招募需求直接可改，改了以后**项目总览和立项向导自动同步**（同一份数据）。 |
| A2 | 左右两边的研究目标、招募需求挤成一段 | 所有文字按段落或条目分行显示，写法像正式文件。研究目标是编号列表、一条一行；左栏 ① 也一样。 |
| A3 | 右侧研究目标是一整条 “1. … 2. … 3. …” | 按编号拆成多条；在某条里按**回车，自动建下一条**；空的“写一条…”不再单独占一行。老数据一次性拆好。 |
| A4 | ② 要筛进谁要一条条手填 | 进入这一步，AI 按研究背景、目标、招募需求**自动生成条件表**。表下方是对话框（和其他对话框同一套样式和功能），用对话来改：“加一条近 12 个月保养过”“城市只要一线”。多轮确认后再“确认，生成这部分题目”。“＋自己加条件”去掉。 |
| A5 | ③ 加了一个空的“新条件”也会出现 | 空条件不出现、不保存。③ 下方也有对话框，AI 自动识别该排除谁，用户确认或要求改。 |
| A6 | ④ 配额要手工加组；合计算错（3+2 显示 4） | 改为**导入配额**：Word、Excel、PDF、PPT、图片都行，图片读图中文字。下方对话框里 AI 识别后输出配额表，让用户确认；也可以说“A 组改成 4 人”。合计实时算对。立项里有配额表时，仍直接引用。 |
| A7 | ⑥ 题太少；测试时只能看 | 题数少于建议数时，AI 按研究背景、目标、人群**主动补题**（列出建议，点采纳才加）。测试答题时每道题旁有对话框，可以边测边改。 |

| # | 现在 | 改成 |
|---|---|---|

| C2 | 底部有两个“继续” | 只留一个，所有同类页面一样。 |

| C4 | 物料已经是“不看素材”，第 3 轮还在问要不要看素材 | “已经知道的”里已经有值的项，不再在下面重复问；只问还没有值的。 |
| C5 | 不做概念或定价研究，也出现“价格怎么谈” | 只有研究类型是概念测试或定价、或者有物料时，才显示“价格怎么谈”。 |
| C6 | 大纲总览里“访谈对象”显示“—”（前一页已经填了） | 前面页面改的所有字段，后面所有地方联动显示。 |
| C7 | “要回答的问题”显示成“1. 1. 对比…” | 去掉重复的编号。 |
| C8 | 进入大纲总览后，“撤销清除”条还在 | 进入大纲总览，就说明已经决定重新来了，撤销条自动消失。 |
| C9 | 进入“题目”里的模块还要点“生成本模块题目” | 进入还没写题的模块时，自动生成题目。 |
| C10 | 题目还没写或模块没确认，也能点“继续” | 每一步没确认前，“继续”不可点。题目这一步，所有模块都确认后才出现“继续”。 |
| C11 | 在对话里接受了 AI 加的题（主持人介绍、项目背景），一“重新生成本模块”就没了 | 接受的修改马上出现在题目里；重新生成这个模块时，把已接受的这些题保留，并且照着它们的要求写。 |
| C12 | 每题有“备选”勾选 | 去掉“备选”。 |
| C13 | 模块名是截断的半句（“2. 识别用户在”“1. 对比本田与”），顺序也乱 | 模块名用 4–8 个字的完整短语（例如“售后痛点”）；顺序按要回答的问题的先后。 |

## 需要用户定的
1. **短信用什么发？** 现在系统只能发邮件，短信要接一个短信服务商。推荐腾讯云短信，和语音识别是同一个账号；但需要在腾讯云申请短信签名和模板，审核约 1–2 个工作日。没开通之前，页面上短信选项是灰的，邮件照常能用。
2. **⑥ 主动补题：** 推荐 AI 列出建议，点“采纳”才加进问卷（和其他地方一致）。另一种是自动加进去。
