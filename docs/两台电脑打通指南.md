# 星桐 MVP:两台电脑打通指南

原则:代码走 Git 私有仓库;密钥、数据库、录像不进仓库,每台电脑各自一份。

## A. 原电脑(已有项目)——只做一次
1. 对 Claude Code 说:"运行 `powershell -ExecutionPolicy Bypass -File scripts/git-init.ps1`,把输出告诉我。"
   - 脚本会初始化 Git、检查 `.env` / 数据库 / 录像没有被加入,然后首次提交。
   - 如果输出 ABORT,不要继续,把内容发给我。
2. 在 GitHub 或 Gitee 建一个**私有**仓库(名字如 `total-mvp`),不要勾选"初始化 README"。建库和登录由你自己完成。
3. 对 Claude Code 说:"添加远程 `git remote add origin <仓库地址>` 并 `git push -u origin main`。"推送时弹出的登录窗口由你自己登录。

## B. 另一台电脑(Windows)——只做一次
1. 安装:Git(git-scm.com)、Python 3.11+(勾选 Add to PATH)、Node.js LTS。
2. 打开 PowerShell:
   ```
   npm install -g @anthropic-ai/claude-code
   git clone <仓库地址> total-mvp
   cd total-mvp
   claude
   ```
   用同一个 Anthropic 账号登录。
3. 对 Claude Code 说:"读 README.md、CLAUDE.md、docs/PROGRESS.md 和 start-dev.ps1,帮我在这台电脑装好环境(Python 依赖、ffmpeg、LiveKit、Playwright),再用 `.env.example` 生成 `.env` 的模板;密钥我自己填,不要读取或回显 `.env`。"
4. 演示数据:让它运行 `scripts/seed.py` 重新生成。数据库不同步,两台电脑各有一份。

## C. 日常配合
- 开工前:`git pull`。收工:`git add -A && git commit -m "说明" && git push`。
- 同一时间只让一台电脑改代码,避免冲突。
- 进度以 `docs/PROGRESS.md` 为准,两边都读。
- 换电脑后,Claude Code 的历史会话不会跟过去,上下文靠 CLAUDE.md 和 PROGRESS.md。

## D. 安全提醒
- 仓库必须是私有。
- 若曾把密钥提交进仓库,要立即在供应商后台作废并重建。
- 密钥不要经聊天、微信或邮件传。
