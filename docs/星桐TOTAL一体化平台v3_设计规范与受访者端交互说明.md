## 第一部分：品牌与视觉规范

### 1.1 品牌

| 项 | 规定 |
| --- | --- |
| 名称 | 星桐 TOTAL |
| 字标 | “星”橙色 #FF6A00；“桐”在深绿底上为白色，在白底上为深绿 #0B382C |
| 动效 | 登录页和顶栏的凤凰 logo 在加载时播放一次展翅动画；开启“减少动效”时不播放 |
| 禁用 | 不使用紫色；不使用奶油/米色大面积底色；不使用渐变装饰 |
| 整体结构 | 用户侧：深绿框架 + 白色画布 + 橙色强调 |

### 1.2 色彩令牌

橙色只给“当前位置”和“主操作”；绿色表示状态；其余层级靠墨绿的明度拉开。

| 令牌 | 浅色值 | 用途 |
| --- | --- | --- |
| `--bg` / `--surface` | #FFFFFF | 页面底、卡片底 |
| `--wash` | #F4F7F5 | 嵌套面板、表格悬停、说明块 |
| `--ink` | #0B2E25 | 主文字 |
| `--ink2` | #2F4A40 | 次级正文 |
| `--muted` | #51675D | 辅助文字（对白底对比度须 ≥ 4.5） |
| `--line` / `--line2` | #E2E8E4 / #C9D4CD | 分隔线 / 控件边框 |
| `--nav` / `--nav-on` | #062319 / #0F3A2C | 左侧导航底 / 当前项底 |
| `--nav-ink` | #9DBBAE | 导航文字 |
| `--orange` | #FF6A00 | 主操作、当前项、焦点环 |
| `--orange-ink` | #B84900（浅色）/ #FF9A55（深色） | 橙色文字链接 |
| `--orange-soft` / `--orange-mid` | #FFF7F0 / #FFE6D2 | 选中行、提示底 |
| `--green` / `--green-soft` | #1F6B54 / #E3F1EA | 成功、已完成、状态标签 |
| `--gold` | #D9B84A | 第三阶段标识 |
| `--risk` / `--risk-soft` | #C62B4B / #F9DDE3 | 错误、风险、录制中 |
| `--room` / `--room-2` / `--room-line` / `--room-ink` | #0E1A16 / #15271F / #24413A / #E8EFEA | 直播间的“深绿”可选主题（默认是白色浅色） |

深色模式：整套令牌有对应深色值（背景 #0A1612，表面 #11211B，文字 #EAF2EE，橙色文字提亮为 #FF9A55）。跟随系统，也可手动指定。

三个研究阶段用固定色区分：第一阶段橙 #FF6A00，第二阶段绿 #6FD3A6，第三阶段金 #E8CF7A。

### 1.3 字体与字号

| 项 | 规定 |
| --- | --- |
| 字体 | Geist（拉丁与数字）+ Noto Sans SC（中文）；泰米尔文回退到 Noto Sans Tamil；数字一律等宽数字（tabular-nums） |
| 页面标题 | 30/38，粗 700，字距 -0.012em（手机 25/32） |
| 卡片标题 | 15，粗 650 |
| 正文 | 14.5/24（长文）；表格与控件 13–14 |
| 辅助文字 | 不小于 12px；连续阅读的长文不小于 14px |
| 行长 | 不超过 80 个字符，长说明限制在 70ch 内 |
| 避免 | 大写字母标签、给标题里某一个词单独上色、每个标题上方都加小标签 |

### 1.4 间距、圆角与层级

- 圆角三级：控件 10px，面板 16px，弹层 20px。胶囊标签 999px。
- 页面左右留白 `clamp(20px, 3.4vw, 48px)`；内容最大宽度 1240px。
- 卡片只有最外层有边框；卡片里再嵌卡片时去掉边框，用 `--wash` 浅底区分。
- 阴影基本不用，仅用于悬浮层：弹窗 `0 28px 80px rgba(6,35,25,.3)`、抽屉、提示条。

### 1.5 组件

**按钮**

| 类型 | 样式 |
| --- | --- |
| 主按钮 | 橙底 #FF6A00、深绿字，高 38–40px，粗 700 |
| 次按钮 | 白底、`--line2` 边框、墨绿字 |
| 深色按钮 | 墨绿底、白字（表示已选中） |
| 小按钮 | 高 30–32px，字 12.5px |
| 文字链接 | 橙色加下划线；悬停时下划线从左向右画出 |
| 禁用 | 透明度 .45，不可点，光标显示禁止 |

悬停动效：底色从左向右铺满（0.36 秒），文字同时变色；图标向右滑 4–5px；按下缩放到 0.97。所有悬停动效在“减少动效”下关闭，只保留颜色变化。

**表单**：边框 `--line2`，聚焦时边框变绿并带 3px 浅绿光圈；下拉框用自绘箭头；勾选框强调色为橙色。

**标签（pill）**：绿 = 正常/已完成，橙 = 待处理，红 = 风险/进行中录制，灰 = 中性。11.5–12px。

**表格**：表头 12px 灰字，行高宽松（单元格内边距 13px 12px），悬停整行变浅，最后一行无下边线。

**进度条**：高 6px（大号 10px），圆角，页面进入时从左向右生长一次。

**弹窗/抽屉/提示条**：弹窗淡入加轻微上浮；抽屉从右侧滑入；提示条居中底部，带橙色圆点，几秒后自动消失。

**键盘焦点**：所有可操作元素有 2px 橙色焦点环，偏移 2px；输入框改用绿色边框加光圈。

### 1.6 布局与导航（研究员/客户侧）

- 左侧深绿导航 244px，吸顶；当前项有滑动的底色块和 3px 橙色竖条；分组标题用阶段色小圆标。
- 顶部“项目上下文栏”吸顶、半透明加模糊：项目名、当前阶段轨道（已完成/进行中/未开始）、方法标识。
- 导航结构（一级）：项目总览 / 立项向导 / 定性 / 定量 / 舆情采集 / 设置。
  - 定性下的二级：受访者招募、场次与邀请、直播间、洞察与片段、AI 访谈、异步活动、物料与提纲、被访者端预览。
- 总览首屏：左侧整体进度大数字 + 分项进度；右侧“星图”可点击跳转。
- 手机宽度（≤ 820px）：导航变成顶部横向滚动，上下文栏不再吸顶，字号和留白相应缩小。

### 1.7 直播间（三栏；默认白色浅色，可切换深绿）

- **默认主题是白色浅色**：白底、墨绿文字、橙色强调，视频小窗用浅灰底。用户可在房间右上角切换为深绿主题（沿用 `--room` 系列色），选择记在浏览器本地，下次沿用。两个主题都必须通过 1.8 的对比度、字号、点击区检查。
- 左：参与者画面与成员；中：舞台（物料/共享屏幕/白板）与转写；右：聊天、观察员备注、要点标记。
- 说话者的画面带橙色描边；录制中显示红色脉冲点。
- 观察员在直播间里只读：可看、可写给主持人的私聊、可标记片段，不能发言或发布任何音视频。

### 1.8 无障碍与质量底线（自动检查项）

| 项 | 标准 |
| --- | --- |
| 对比度 | 正文 ≥ 4.5:1（WCAG AA） |
| 点击区 | 手机端 ≥ 36px（建议 44px） |
| 字号 | 控件和辅助文字 ≥ 12px，长文 ≥ 14px |
| 键盘 | 全站可用 Tab 操作，焦点可见 |
| 动效 | 尊重“减少动效”设置 |
| 溢出 | 手机宽度不出现横向滚动条 |
| 按钮文字 | 不换行，不被截断 |
| 控制台 | 页面无报错 |
| 语言 | 受访者页面在英、中、马来、泰米尔四种语言下都通过上述检查 |

## 第二部分：受访者端视觉规范

受访者端与研究员端是两套气质：**明亮、简单、一次只做一件事**，不显示任何内部信息。

| 项 | 规定 |
| --- | --- |
| 底色 | 白底 #FFFFFF，文字墨绿 #0B382C，辅助灰 #55645C |
| 顶部 | 深绿条 + 凤凰 logo（高 44px），载入时播放一次 |
| 主操作 | 全宽橙色大按钮，高 52px，圆角 16px，字 16px 粗 700 |
| 选项 | 整行可点，最小高度 50px，圆角 14px；未选边框 #EAE3D3；选中边框橙色、底 #FFF4EA |
| 必选/可选 | “必选”红字 #C62B4B，“可选”灰字 |
| 进度 | 顶部 6px 橙色进度条；题目页另有“第 n / 共 N 题” |
| 错误 | 红色 #C62B4B 粗体，`role="alert"`；写清怎么办，不道歉 |
| 单屏宽度 | 手机优先，内容最大宽度 440px，居中 |
| 语言 | 页面所有文字跟随同意书语言（英/中/马来/泰米尔），不混用 |
| 隐私 | 不显示访谈标题、其他受访者、观察员名单；房间里主持人以“Moderator/主持人”显示，受访者自己显示为“我/You” |

## 第三部分：受访者端交互说明（原型 v3 的完整旅程）

### 3.1 深访/座谈会旅程（9 步）

原型的“被访者端预览”页用手机框演示整条路径，右侧同时显示研究员那边会看到什么。

| 步 | 页面 | 受访者做什么 | 研究员那边同步看到 |
| --- | --- | --- | --- |
| 0 | 访谈邀请 | 看项目名、时长、时间、礼金、参与方式；点“接受邀请，开始”或“暂时不方便” | 邀请状态：已发送 → 已打开；点暂不方便会通知研究员 |
| 1 | 登录 | 输入邀请短信里的用户名（只读）和临时密码；可点“忘记密码？重新发送” | 登录成功后状态：已打开 |
| 2 | 访谈前小问题 | 填写预访问任务（文字题必填，截图上传可选） | 答案进入受访者档案，主持人可见 |
| 3 | 选择时间 | 在 3 个候选时间里选一个，时间按本人时区显示；确认后收到日历邀请和开始前 1 小时提醒 | 状态：已排期 |
| 4 | 测试设备 | 逐项检测摄像头、麦克风（带音量条）、扬声器（播放提示音）、网络；失败项显示红字和具体处理办法；**麦克风必须正常才能继续**（摄像头可以不开） | 通过后状态：检测通过，在候场室出现 |
| 5 | 隐私与同意 | 逐项勾选：参与研究、录音录像、AI 转写与翻译、数据传输到境外（必选）；观察员只看编号、以后可再邀请（可选）；可“勾选全部必选项” | 同意记录写入合规留痕；观察员只看编号 |
| 6 | 候场室 | 看状态（等待开始 / 请稍等 / 已放行）；**主持人开始访谈并放行后**“进入访谈室”按钮才可点；提示使用耳机、保持安静 | 候场室里能看到该受访者；主持人在房间左栏“候场室”里对每位放行或暂缓 |
| 7 | 访谈室 | 见 3.2 | 状态：已进入；直播间画面出现该受访者，摄像头/麦克风开关同步 |
| 8 | 感谢页 | 看到“谢谢您”、礼金发放时间、参与状态；可去“我的隐私”查看/导出/删除数据 | 状态：已完成，礼金流程触发 |

每一步左上角有“← 上一步”（第 0、7、8 步除外）。步骤条在手机框上方：当前步橙底，已完成步绿底。

### 3.2 访谈室（第 7 步）

主题：默认白色浅色，右上角可切换为深绿；选择记在浏览器本地。

自上而下：
1. **顶栏**：场次名 + 红色“● 进行中”标签。
2. **成员小窗**：主持人（深绿底）、自己（橙色描边）；座谈会再加其他参与者，只显示编号后两位和“参与者”。
3. **实时字幕**：最近 4 句，标注说话人（主持人/我/参与者），实时翻译成受访者的语言。
4. **物料区**：主持人展示物料时出现提示条“主持人展示了「…」”和按钮“在上面圈出喜欢和不喜欢”，点开后可在物料上标注（见 3.4）。
5. **聊天区**：最近几条文字消息；输入框 + “发送”；回车也可发送。
6. **控制条**：摄像头开/关、麦克风开/关、语音转文字、举手、离开。按钮选中态为橙色描边。
7. **其他**：主持人开启时出现“共享屏幕”（测网站/App 流程）；白板任务时可拖动排序。

规则：
- 摄像头可随时关闭，不影响参加；
- 离开后不能无提示重进，需要主持人再放行；
- 页面每 3 秒刷新一次状态，输入框聚焦或正在标注时不刷新。

### 3.3 定量问卷旅程（4 步）

| 步 | 页面 | 内容 |
| --- | --- | --- |
| 0 | 问卷邀请 | 项目名、约 8 分钟、题目数、语言、礼金说明；“开始” |
| 1 | 隐私与同意 | 三项必选：参与调研、AI 处理开放回答和语音、数据传输到境外；全勾才可继续 |
| 2 | 答题 | 顶部进度条 + “第 n / N 题”；单选为整行选项；打分题为一排数字按钮并标注 1 = 很不满意、5 = 很满意；开放题为多行输入，可附语音/图片；未作答时“下一题”不可点；最后一题按钮变为“提交，看概念” |
| 3 | 概念测试 | 看概念卡，点按位置标注喜欢/不喜欢（见 3.4）；“完成” |
| 4 | 完成页 | “完成，谢谢”；质控通过后发放礼金；可勾选“以后可以邀请我做访谈” |

研究员侧同步：点开链接计入“总点击”；同意写入合规留痕；作答中计入“未完成”；提交后计入“完成”，配额 +1。

### 3.4 概念卡与视频圈选

- 概念卡是一块白色区域，点按任意位置放置一个标记：绿色 ♥ = 喜欢，红色 ✕ = 不喜欢。
- 按钮区有“喜欢/不喜欢”切换（选中时绿框/红框，点击区 ≥ 44px）。
- 标记以百分比坐标保存，不同屏幕尺寸下位置一致。
- 视频物料：先播放，暂停时可标注，标注带时间点。
- 汇总：全体标记叠加成热区，进入洞察。

### 3.5 状态机（受访者邀请）

`已发送 → 已打开 → 已排期 → 检测通过 → 已进入 → 已完成`
其他出口：`暂不方便`（通知研究员）、`拒绝/未通过甄别`、`中途退出`（链接有效期内可重新进入）、`超时未响应`。

### 3.6 失败与边界

| 场景 | 界面行为 |
| --- | --- |
| 摄像头被拒绝 | 红字 + 处理步骤：在地址栏允许摄像头，点“重新检测” |
| 麦克风被占用 | 提示关闭其他软件后重新检测 |
| 网络慢 | 提示靠近路由器或改用热点 |
| 链接无效/过期 | 显示“链接无效”，说明联系邀请人要新链接；中英并列 |
| 不满足国家/地区条件 | 礼貌说明暂无法参加，不暴露内部规则 |
| 访谈未开始 | 候场室显示“等待主持人开始…”，按钮不可点 |
| 中途断线 | 保持页面，自动重连；重连失败显示“连接已断开，请刷新” |
| 访谈已结束 | 显示感谢，所有人被移出，房间关闭 |
| 同意被拒绝（取消勾选关键项） | 不让继续，并说明不同意直接关闭页面，不会有任何影响 |

## 第四部分：MVP 已实现的受访者端（真实可用）

MVP 只做深访 1:1，受访者路径：**邀请 → 设备检测 → 隐私与同意 → 候场室 → 访谈室 → 结束**（`/join.html?t=邀请令牌`，顶部步骤条）。没有登录、预访问任务（问卷由另一个平台通过接口接入）、选时间（由研究员定时间）。

### 4.0 设备检测与候场室（2026-10-10 加入）

- 设备检测：摄像头、麦克风（带音量条）、扬声器（播放提示音）、网络四项；失败项红字写清处理办法。**麦克风正常才能点“继续”**，摄像头不开也可以参加。服务端同样把关：没通过检测的人拿不到进房令牌。
- 候场室：每 3 秒刷新；显示“等待主持人开始 / 主持人请你再稍等 / 已放行”。主持人开始访谈 **并且** 在房间左栏“候场室”点了“放行”，“进入访谈室”才可点。服务端同样把关：没放行的人拿不到进房令牌。
- 受访者在房间里点“离开”后，要重新打开链接并等主持人再次放行；刷新页面不算离开，会自动重连。
- 研究员端“场次与邀请”按 已发送 → 已打开 → 检测通过 → 已同意 → 已进入 → 已完成（或 未到场）显示每人进度；“直播间”列表显示“候场中，等你放行”。
- 房间配色：默认白色浅色，右上角可切换深绿，选择只记在本浏览器里；两种配色都通过 1.8 的全部检查。

### 4.1 同意页 `/join.html?t=邀请令牌`

- 顶部深绿条 + 凤凰 logo。
- 标题“访谈邀请”，副标题“由 {机构} 邀请 · {时间}”。
- 同意正文（按语言），内容覆盖：目的、录制与转写翻译、不向委托方提供姓名联系方式、观察员静默旁听、数据存放在新加坡由中国团队访问、项目结束后 180 天删除、撤回与访问更正删除的联系邮箱。
- 国家/地区下拉（必选）；**首批市场只开新加坡**，其他地区会被礼貌拒绝。
- 三个独立勾选：同意录制；知道观察员可能静默旁听；同意数据存放新加坡并由中国团队访问（单独同意）。三项都勾才能点“同意并继续”。
- 页面下方说明：不同意直接关闭页面，不会有任何影响。
- 已同意过的人再打开：显示“你已经同意过了”；到访谈时间显示“进入访谈”按钮，否则提示“还没到时间，或访谈已结束，到时间后刷新”。
- 页面语言跟随同意书语言：en / zh / ms / ta，不混用。

### 4.2 访谈室 `/room.html?t=…`

- 进入时请求摄像头和麦克风；摄像头不可用则只用麦克风加入并提示；都不可用则显示指引。
- 主持人显示为“主持人/Moderator”；受访者自己显示为“我/You”；真实姓名**从不**出现在房间里（令牌名固定为 Participant）。
- 状态文案：已进入等待 → 访谈进行中 → 已结束；页面每 2 秒轮询状态。
- 录制指示：主持人点“开始录制”后，受访者页面出现红色脉冲点和“正在录制/Recording”。
- 按钮：麦克风开/关、摄像头开/关、离开。开关通过关闭媒体轨道实现，因此录像里反映真实状态。
- 刷新页面：自动重连并续录，不丢已录部分。
- 观察员永远不出现在受访者画面里，也不会被录进去。
- 访谈结束：所有人被服务器移出房间，受访者看到感谢语。

| 能力 | v3 原型 | MVP 现状 |
