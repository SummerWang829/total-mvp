# 账号邮件开通说明

**用途**：邀请成员、重置密码、忘记密码三类邮件由系统自动发出。代码已就绪（`app/mailer.py`），没配置发信服务时一切照旧：管理员复制链接手动发。

## 推荐：腾讯云「邮件推送」（SES）
理由：已在用腾讯云和 DNSPod（域名 morningstarsystem.tech 的解析在那里），验证域名的记录可以直接加。

**用户要做的（我带着做，和开 COS 一样：你登录，我告诉你点哪里）**
1. 控制台搜「邮件推送」并开通，地域选新加坡或最近的可用地域。
2. 添加发信域名 `morningstarsystem.tech`，控制台会给出 3 到 4 条解析记录（SPF、DKIM、DMARC 等）。
3. 把这些记录加到 DNSPod（我可以替你加，前提是你给 DNSPod 的授权；或你自己复制粘贴）。
4. 创建发信地址，比如 `no-reply@morningstarsystem.tech`，并创建 SMTP 密码。
5. 密码不要发给我；和 COS 一样，用文件导入脚本（我会提供 `deploy/set-mail-keys.sh`，思路同 `set-cos-keys.sh`）。

**服务器 .env 要填的 7 项**
```
MAIL_HOST=smtp.qcloudmail.com   （以控制台显示的为准）
MAIL_PORT=465 或 587
MAIL_SECURITY=ssl 或 starttls
MAIL_USER=no-reply@morningstarsystem.tech
MAIL_PASSWORD=（SMTP 密码，只放服务器）
MAIL_FROM=星桐 <no-reply@morningstarsystem.tech>
PUBLIC_BASE_URL=https://deepresearch.morningstarsystem.tech
```
`MAIL_HOST`、`MAIL_FROM`、`PUBLIC_BASE_URL` 三项缺一项，功能就保持关闭。

## 投递质量（防进垃圾箱）
- SPF、DKIM 必须通过；DMARC 先用 `p=none` 观察，稳定后再收紧。
- 发件地址用同一个域名，别用个人邮箱。
- 邮件里只有一条链接、没有图片和附件；中英文双语。

## 安全约定（已写进代码和测试）
- 忘记密码：无论邮箱是否存在，页面和接口回答完全一样（不泄露谁有账号）；每个地址每小时最多 5 次、每个账号最多 3 次，超出静默不发。
- 自己申请的重置链接 1 小时有效、一次性；管理员发的邀请和重置链接 7 天、一次性。一个账号同时只有一条有效的“忘记密码”链接。
- 邮件正文含一次性链接，所以发送成功或放弃后，发件箱里的正文立刻清空；记录保留 14 天后删除。
- 发信失败自动重试：1、5、15、60 分钟后各一次，第五次失败放弃；日志只记错误类型，不记地址和正文。
- 邮箱验证：收到邀请链接并设好密码，本身就证明了邮箱归本人所有，所以不另做验证邮件。公开注册已关闭；将来若重新开放，再加注册验证。

## 验证
`python -m app.doctor` 会显示“账号邮件：已配置 … 发件箱待发 N 封”。上线后用自己的邮箱走一遍：团队页“邀请成员”勾选发邮件，以及登录页“忘记密码”。
