# 界面改动后的自检流程

规范来源：`docs/星桐TOTAL一体化平台v3_设计规范与受访者端交互说明.md`（以下简称“规范”）。

## 必做
1. 跑 `scripts/qa.sh`，必须全绿；不许为通过检查而删检查或放宽阈值，确需放宽先问用户。
2. 用浏览器打开本机页面（`http://localhost:8000`），每个改动过的页面都截图：桌面宽度和手机宽度（约 390px）各一张，存到 `qa_shots/`。
3. 访谈房间页必须在**浅色（默认）和深绿**两个主题下各截图、各检查一次。
4. 逐项对照规范：
   - 颜色用规范里的令牌，不用紫色，不用奶油底，不用渐变装饰
   - 字号：控件与辅助文字 ≥ 12px，长文 ≥ 14px
   - 对比度 ≥ 4.5:1，手机点击区 ≥ 36px
   - 键盘 Tab 可操作、焦点环可见；“减少动效”下无动画
   - 手机宽度无横向滚动；按钮文字不换行
   - 空页面写清“这里会出现什么、下一步点哪里”；错误提示写清怎么办，不道歉
5. 受访者页面在 en / zh / ms / ta 四种语言下都要检查，不混用语言。
6. 肉眼看截图：对齐、留白、层级、有没有被遮挡或溢出。
