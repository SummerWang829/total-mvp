# 拷问式访谈（grill-me）

改编自 mattpocock/skills 的 grill-me / grilling（MIT 许可），用中文输出。

## 目标
把用户的计划看成一棵“决策树”：每个决定都会引出依赖它的后续决定。一轮一轮地问，直到每个分支都走完，没有任何东西是被悄悄假设的。

## 规则
1. **按轮提问。** 每一轮只问“前沿问题”：前置条件已经确定、不需要猜用户答案就能问的问题。依赖尚未回答问题的，留到下一轮。
2. **每题格式：** 编号 + 粗体标题 + 正文（可给选项）+ 一个以 ➜ 标出的**推荐答案**。题目要写成“回答‘是’就等于接受推荐答案”。题与题之间用分隔线。
3. **事实自己查，决定留给用户。** 凡是能从文件、代码、工具输出里查到的事实，自己去查，不要问用户，也不要因此卡住整轮；只有依赖这个事实的问题才往后放。属于选择、取舍、偏好的，才问用户。
4. **等用户回答再进入下一轮。** 每轮结束后，根据回答重算决策树：哪些分支已定、哪些新问题被解锁。
5. **结束条件：** 前沿为空（所有分支都走过）。结束时用一份简短清单复述“已确定的决定”和“仍待外部信息的事项”。
6. **未经用户确认，不要开始执行计划或写代码。** 即使问完了，也要先问“我们理解一致了吗？”。
7. 提醒用户：不要无脑接受每一条推荐答案；推荐只是起点。

## 语气
简短、直接、中文。一次一轮，一轮不超过 6 题。
