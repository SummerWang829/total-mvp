## 三、环境（⚠ 这次有要加的配置）
1. **图片附件读文字（用户特别要求提醒）：** 在服务器 `.env` 加 `OCR_PROVIDER=tencent`。
   - `TENCENT_OCR_SECRET_ID` / `TENCENT_OCR_SECRET_KEY` 不填，就沿用 `TENCENT_ASR_SECRET_ID` / `TENCENT_ASR_SECRET_KEY`（同一个腾讯云账号）。这个账号要在腾讯云控制台**开通“文字识别 OCR”服务**。
   - 可选 `TENCENT_OCR_REGION`，默认 `ap-guangzhou`。
   - 不配的话，上传图片只会提示“图片文字识别还没配置”，其他功能不受影响。
2. **语音输入用“实时识别”（用户已选定）：** 和访谈实时字幕是同一个服务，需要 `TENCENT_ASR_APPID`、`TENCENT_ASR_SECRET_ID`、`TENCENT_ASR_SECRET_KEY` 都已配置（线上字幕在用的话就已经有了）。实时识别不可用时，自动改用分段识别（一句话识别）。
3. **邮件（可选）：** Pilot 旁听邀请、立项解锁申请会发邮件。没配 `MAIL_HOST` / `MAIL_FROM` / `PUBLIC_BASE_URL` 时，页面会给出链接让人复制，不影响使用。
4. `MODERATOR_VENDOR` 必须已填（和以前一样）。
5. **没有新依赖，`requirements.txt` 没变**（Excel 用标准库读）。
6. 服务器要能**出网访问公网网页**：贴链接时由服务器读取页面。内网、本机、云服务器元数据地址一律拒绝。

改完 `.env` 后再重建容器（第四节）。**不要把密钥写进任何回报或日志。**
