# 星桐 TOTAL · MVP（深访 1:1）

范围：登录/组织/角色 → 项目 → 受访者 → 邀请 + 四语同意 → 三角色视频房间 → 录制 → 转写 → 带原文回链的洞察 → 片段 → 带水印分享链接。
不含：定量、爬虫、供应链、座谈会（多人房间）、异步活动、计费。

## 在自己电脑上跑起来（一条命令）

    scripts/dev.sh        # 装依赖、下载并启动视频服务器、启动网站、造好演示账号和一场演示访谈
    # 然后打开 http://localhost:8000（终端会打印账号和受访者邀请链接）

需要先装好 Python 3.10+ 和 ffmpeg（Mac：`brew install ffmpeg`）。`python -m app.doctor` 会用中文告诉你还缺什么。
停止：终端里按 Ctrl+C。改过数据库结构后，删掉 `total.db` 再启动。

## 真人测试清单（一个人也能测完整流程）
用 **同一台电脑的两个浏览器**（例如 Chrome 和 Chrome 无痕窗口，或 Chrome + Edge）：
1. 浏览器 B（无痕）打开终端里打印的受访者邀请链接，走受访者流程：接受邀请 → 设备检测（允许摄像头麦克风）→ 选国家、勾三项同意 → 进入候场室等待。
2. 浏览器 A 登录 `researcher@demo.test`，左侧“场次与邀请”里能看到这位受访者的进度变成“已同意”。
3. 浏览器 A 另开窗口用 `moderator@demo.test` 登录，左侧“直播间” → “进入 TA 的房间”，允许摄像头和麦克风，点“开始访谈”，再在左栏“候场室”里点“放行”。受访者的候场室按钮变亮，点“进入访谈室”。（房间默认白色，右上角可切换深绿。）
4. 再开一个窗口用 `observer@demo.test` 登录，“直播间” → “隐身观察”：能看到两人，但主持人和受访者都看不到观察员。
5. 主持人点“开始录制”（受访者那边应出现“● Recording”）→ 随便聊 20～30 秒 → “停止录制”。
6. 主持人点“结束访谈”：受访者页面出现感谢语，所有人被移出房间；“场次与邀请”里进度变成“已完成”。
7. 研究员在“洞察与片段”里点这场的“查看详情” → 转写：录像“合成中”几十秒后变“已就绪”，可以播放；点“转写录制”。
8. “洞察”里点“AI 生成洞察” → 通过 → 在证据下点“生成片段” → “片段”页点“预览”“创建分享链接”；用无痕窗口打开分享链接，应看到带水印、不能下载的短视频。
同一台电脑上两个窗口共用一个麦克风会有回声，请戴耳机，或把其中一个窗口的“麦克风”关掉。手机/别人的电脑要测，需要先部署到有 https 的地址（浏览器规定：非 localhost 的页面必须 https 才能用摄像头）。

## 哪些是真的，哪些还是演示
| 部分 | 现在 |
|---|---|
| 视频房间（三角色、观察员隐身、结束时清场） | **真的**：本机 LiveKit；已用 3 个真实浏览器自动测过 |
| 录制 | **真的**：主持人和受访者的浏览器各录自己的画面声音，分片上传，服务器合成一个 MP4（并排画面、混音）；中途刷新页面会自动续录 |
| 片段 + 水印 | **真的**：服务器剪出短片并烧入水印，客户只拿到成片 |
| 转写 | `ASR_PROVIDER=mock` 时是**固定示例对话**（按录音长度压缩时间）；填 key 后用真实语音识别 |
| 洞察 / 中文翻译 | `LLM_PROVIDER=mock` 时是简单摘录；填 key 后用大模型，证据仍会和转写逐字核对 |

要真实转写+洞察+翻译：在 `.env` 里设 `ASR_PROVIDER=openai`、`LLM_PROVIDER=openai`、`LLM_API_KEY=你的密钥`（任何兼容 OpenAI 接口的服务都行，三者共用一个密钥），重启。`python -m app.doctor` 会检查密钥能不能用。
马来语、泰米尔语的转写质量**没有实测过**，是最大风险，找真实录音测。

## 角色
| 角色 | 能做什么 |
|---|---|
| admin | 全部，含团队与审计日志 |
| researcher | 项目、受访者、访谈、转写、洞察审核、片段、分享 |
| moderator | 只看分配给自己的访谈；开始/结束、录制、进房间 |
| observer（客户） | 只看被指派的访谈；隐身进房间；看不到受访者姓名；只看已通过的洞察 |

观察员隔离在服务端的令牌里（`app/livekit.py`）：只订阅、`hidden`、不能发布、不能发数据。受访者的真实姓名不会进入视频房间。不靠前端隐藏。

## 检查（交付前必跑）
`scripts/qa.sh` 依次跑三层，全绿才算完成（第一次跑之前先执行一次 `python -m playwright install chromium`，下载测试用的浏览器）：
1. `pytest`：权限、租户隔离、同意、录制上传与合成、转写、证据校验、水印、保留期……
2. `tests/qa_site.py`：真实浏览器遍历 4 种角色 × 所有页面 × 桌面/手机：控制台错误、溢出、死链、字号、对比度、点击区、文字换行、焦点环、四语受访者页、权限显隐、动效。
3. `tests/e2e_room.py`：**真实 LiveKit + 3 个真实浏览器**走完整条真人流程（同意 → 进房 → 互相看到听到 → 观察员隐身且不能发布 → 录制（含中途关摄像头、刷新页面）→ 合成 → 转写 → 洞察 → 片段 → 分享页 → 结束清场），截图在 `qa_shots/`。
测试用的浏览器没有 H.264 解码器，所以“网页里真的播放视频”这一项用“媒体响应 + ffprobe 解析”代替；Chrome/Edge/Safari 都能播放。
